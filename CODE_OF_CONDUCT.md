# Code of Conduct

## Our commitment

We want PrivateSecretary to be a welcoming, respectful project for builders of all backgrounds and experience levels.

## Expected behavior

- Be direct and kind.
- Critique ideas and code, not people.
- Respect privacy. Do not post another person's data, messages, credentials, or screen captures.
- Ask before sharing logs or screenshots that may contain personal information.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Publishing private data without consent.
- Using issues or pull requests to promote unrelated products.
- Deliberately weakening the read-only boundary or introducing hidden data collection.

## Enforcement

Maintainers may edit, remove, or reject contributions and comments that violate this code. Repeated or serious violations may result in a ban from the project spaces.

Report concerns to the maintainers through a private GitHub Security Advisory or the contact method listed on the repository profile.

This is a lightweight code of conduct for a small open-source project. Be a good builder.
