# ADR 0005：L0 屏幕环保存变化事件，而不是可回放像素帧

- 状态：Accepted
- 日期：2026-11-06

## 背景

PRD 写“屏幕事件 30 帧”。如果字面保存 30 张全屏图，会带来隐私风险和内存压力，且与“原始像素不长期驻留”的承诺冲突。

## 决策

- L0 音频环保存 60s 16k Float32 样本，仅内存；
- 屏幕环保存 `ScreenEvent`：时间、变化比例、变化区域、感知签名；
- 原始 CGImage/CVPixelBuffer 只在 capture callback 的局部作用域存在；
- OCR 在 callback 内完成，长期只保存文本与区域；
- 长期 schema 中没有图像 BLOB。

## 后果

正面：

- 满足“当前处理窗口”的语义，内存可控；
- 崩溃不留下屏幕录像；
- 变化区域仍可用于 OCR 过滤和诊断。

负面：

- 不能事后回看原始画面；
- 若 OCR/模型失败，原始画面不可恢复；
- 与 PRD 字面“30 帧”不同，需要在 PRD 第五部分说明。

## 备选

- 保存压缩缩略图：仍有屏幕内容持久化，被否决；
- 完全不留屏幕事件：失去去重/变化诊断能力，被否决。
